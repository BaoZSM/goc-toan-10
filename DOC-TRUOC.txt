CẬP NHẬT TỔNG HỢP

Gồm:
1. Giáo viên chọn mục để đăng file: Tài liệu giáo viên (mục chung), Tài liệu PDF, hoặc Bài 1 … Bài 9.
2. Tài khoản khách không còn thấy Bảng thi đua lớp. Trang tải nhẹ hơn (logo, ảnh bìa, máy tính tách thành file riêng).
3. Giao diện điện thoại mới: thanh mục to ở dưới cùng, nút "Tất cả mục", chữ và nút to hơn.
4. Ô tìm kiếm chung ở trang chủ (bài học, công thức, luyện tập, video, tài liệu, bài hát, hướng dẫn).

Cách cập nhật (GitHub Desktop):
1. Mở thư mục repo goc-toan-10 trên máy.
2. Chép đè vào thư mục gốc của repo: index.html, vercel.json, HUONG-DAN-VERCEL.md.
3. Chép CẢ THƯ MỤC static vào thư mục gốc của repo (thư mục mới, nằm cạnh index.html).
4. Chép đè 2 file trong api: api/tailieu.js và api/diem.js (các file khác trong api giữ nguyên).
5. GitHub Desktop: Summary ghi "Cap nhat tong hop", bấm Commit rồi Push origin.
6. Đợi Vercel cập nhật khoảng 1 phút. Trên điện thoại nếu vẫn thấy giao diện cũ thì tải lại trang (kéo xuống để làm mới).

Lưu ý: KHÔNG thêm file mới nào khác vào thư mục api (đã đủ 12 chức năng, đúng giới hạn gói miễn phí của Vercel).
