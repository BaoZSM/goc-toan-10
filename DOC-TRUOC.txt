BẢN CẬP NHẬT ĐẦY ĐỦ (đã bỏ bản sửa "Tiện ích nổi" mới nhất)

Gồm tất cả cập nhật trước đó: tài liệu giáo viên (chọn mục đăng), ẩn thi đua với khách,
trang nhẹ hơn, giao diện điện thoại mới, tìm kiếm chung ở trang chủ, máy tính cầm tay,
hướng dẫn sử dụng, thống kê học tập, gửi ảnh cho AI, bài hát mới.

CÁCH CẬP NHẬT (GitHub Desktop) - làm đủ cả 4 bước, đây là chỗ hay sót nhất:
1. Chép đè vào THƯ MỤC GỐC của repo: index.html, vercel.json, HUONG-DAN-VERCEL.md
2. Chép CẢ THƯ MỤC static vào thư mục gốc (nằm cạnh index.html).
   Bên trong phải có đủ 3 file:
     calc.14cb4ce1.js
     cover-infographic.2f83f31d.jpg
     logo-ltk.b981e503.webp
   Thiếu thư mục này thì trang mất logo, mất ảnh bìa và máy tính không mở được.
3. Chép đè vào thư mục api: tailieu.js và diem.js (các file khác trong api giữ nguyên).
4. GitHub Desktop: kiểm tra danh sách bên trái có các file trong static/ được thêm,
   ghi Summary "Cap nhat day du", bấm Commit rồi Push origin.

Sau khi Vercel báo Ready (~1 phút): mở trang, bấm Ctrl + F5 (máy tính)
hoặc tải lại trang (điện thoại) để bỏ bản cũ trong bộ nhớ.
